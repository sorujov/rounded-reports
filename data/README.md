# Data

Place the public-use U.S. Census Bureau files here before running the scripts in `../empirics/`:

- `emp/`: American Community Survey 2022 one-year PUMS files (`acs22_person_ca.csv.gz`, `acs22_housing_ca.csv.gz`, and the person files for Mississippi and Puerto Rico);
- `cps/`: one-person household extracts `onep_<year>.csv` built from the CPS ASEC public-use files.

The files are available from https://www2.census.gov and are not redistributed here.
